## 🚀 Sobre o Projeto
O projeto utiliza uma estrutura limpa e organizada em **HTML5** e **CSS3**, aplicando conceitos modernos de layout (Flexbox) para garantir que as imagens fiquem perfeitamente alinhadas e com tamanhos padronizados.
